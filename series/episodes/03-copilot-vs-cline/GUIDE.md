## ⚡ 3-Minute Setup: Autonomous Coding in VS Code

### Step 1: Install Cline in VS Code (30 Seconds)
1. Open **Visual Studio Code**.
2. Press `Ctrl + Shift + X` (Windows) or `Cmd + Shift + X` (Mac) to open Extensions.
3. Search for **`Cline`** (Autonomous coding agent by Cline Bot Inc).
4. Click **Install**.
5. You'll see the robot icon appear in your VS Code activity sidebar.

### Step 2: Connect DeepSeek Engine ($0 Free Tier)
1. Click the **Cline robot icon** in the sidebar.
2. Click the ⚙️ **Settings** gear at the top.
3. Under **API Provider**, select **`DeepSeek`** (or select **`OpenRouter`** and search for `deepseek/deepseek-chat`).
4. Paste your free API key (or select **`Ollama`** if you prefer running 100% locally offline with zero API keys).
5. Click **Save**.

### Step 3: Run Your First Autonomous Coding Task!
In the Cline chat input, try a prompt like:
```txt
Create a clean modern Next.js landing page with Tailwind CSS for a tech podcast, add interactive soundboard audio, and run the dev server to test it.
```
Watch Cline:
1. Read your existing project structure.
2. Create component files.
3. Install dependencies via terminal.
4. Verify there are no TypeScript errors.
